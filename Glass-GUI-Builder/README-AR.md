# KNOUX Repair Glass GUI v1.0

واجهة Windows محلية فاخرة لتحويل مشروع **KNOUX Repair** إلى تطبيق EXE واحد، من دون Electron أو Node.js أو npm أو إنترنت.

## ما الذي تحصل عليه؟

- ملف `KnouxRepair.exe` حقيقي مبني بـ C# وWindows Forms.
- تشغيل بصلاحية Administrator مرة واحدة.
- تصميم Dark Glass / Acrylic بالأزرق الداكن والسماوي والذهبي.
- عرض 10 أقسام و100 أداة من `TOOLS-MANIFEST.json`.
- أسماء عربية داخل الواجهة، مع بقاء مخرجات PowerShell الإنجليزية كما هي.
- بحث مباشر بالاسم أو Tool ID أو مستوى الخطورة.
- بطاقات بيان: إجمالي الأدوات، الأدوات الآمنة، أدوات المسؤول، وعدد التقارير.
- وضع `Analyze-only` مفعّل افتراضيًا.
- تشغيل الأداة داخل الواجهة بدون نافذة Console منفصلة.
- عرض مخرجات PowerShell لحظة بلحظة.
- مربع إدخال تفاعلي لإرسال `Y/N` أو أي اختيار تطلبه الأداة.
- زر إيقاف للعملية الحالية.
- تشغيل Test Suite من الواجهة.
- فتح مجلد Reports.
- قفل عملية واحدة لمنع تشغيل أداتين في الوقت نفسه.
- يعمل من أي قرص أو مجلد بعد وضع EXE في جذر المشروع.

## البناء الأسهل

1. فك ضغط هذا المجلد.
2. اضغط مرتين على:

```text
INSTALL-AND-BUILD.cmd
```

3. اختر مجلد KNOUX Repair الذي يحتوي على:

```text
Config
Core
Docs
Tests
```

4. سيتم إنشاء:

```text
KnouxRepair.exe
START-KNOUX-REPAIR-GUI.cmd
```

داخل جذر المشروع.

## البناء بعد نسخ Builder داخل المشروع

شغّل:

```text
BUILD-KNOUX-REPAIR-EXE.cmd
```

## المتطلبات

- Windows 10 أو Windows 11.
- .NET Framework الموجود مع Windows.
- لا يحتاج إنترنت.
- لا يحتاج Visual Studio.
- لا يحتاج npm أو Node.js.
- لا يحتاج تثبيت مكتبات خارجية.

## الأمان

- التطبيق يبدأ بصلاحية Administrator لأن أدوات صيانة النظام تحتاجها.
- `Analyze-only` هو الوضع الافتراضي.
- قبل التشغيل الفعلي تظهر رسالة تأكيد.
- واجهة GUI لا تغير محتوى الأدوات نفسها؛ هي مشغّل منظم لها.
- راجع نتائج الأدوات والتقارير قبل اعتماد أي عملية إصلاح أو حذف.

## ملاحظة مهمة

التطبيق يرسل ردود المستخدم إلى PowerShell من مربع الإدخال داخل الواجهة. عندما يظهر سؤال مثل:

```text
Proceed? [Y/N]
```

اكتب `Y` أو `N` في مربع الإدخال واضغط Enter أو زر إرسال.
