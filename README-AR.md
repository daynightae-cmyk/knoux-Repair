# نوكس ريبير v2.0 (knoux Repair v2.0)

حزمة صيانة ويندوز تعمل دون اتصال — 10 فئات × 10 أدوات = **100 أداة**، مع وحدات Core مشتركة
لـ PowerShell، ونموذج أمان مبني على مستويات الخطر، وتقارير قابلة للقراءة آليًا.

| | |
|---|---|
| الإصدار | 2.0.2 |
| المنصة | ويندوز 10 / 11، باورشيل 5.1+ |
| اللغة | إنجليزية للواجهة مع تقارير ثنائية اللغة (EN + AR) |

## المحتويات

- **100 أداة** في 10 فئات: صيانة النظام، تنظيف النظام، الشبكة والإنترنت، البرامج والتطبيقات،
  الملفات المكررة، مساحة القرص، الخدمات والعمليات، الأداء، الأمان، التشخيص والتقارير.
- **وحدات Core** (`Core\`): تسجيل، تقارير، بوابات أمان، استدعاء أوامر النظام، حجر العزل،
  نقاط الاستعادة، النسخ الاحتياطي، فحص الملفات المكررة.
- **الإعدادات** (`Config\`): قائمة الأدوات، الإعدادات، المسارات والعمليات المحمية.
- **القائمة** (`Menu.ps1`) والمشغّل (`START-KNOUX-REPAIR.cmd`).
- **الاختبارات** (`Tests\`): 83 اختبارًا آليًا.
- **التوثيق** (`Docs\`): فهرس الأدوات، نموذج الأمان، أدلة الاستعادة، تقارير التدقيق،
  القيود المعروفة.

## البدء السريع

1. اضغط بزر الفأرة الأيمن على `START-KNOUX-REPAIR.cmd` واختر **تشغيل كمسؤول**.
2. اختر فئة ثم أداة. لكل أداة وضعان:
   - **عادي** — ينفّذ العملية.
   - **تحليل فقط** — يفحص ويقدّم تقريرًا دون أي تغيير (مفتاح `A` في القائمة).
3. تُكتب التقارير في `Reports\<timestamp>-<ToolId>\`:
   `summary-en.txt`, `summary-ar.txt`, `results.json`, `results.csv`, `operation.log`, `errors.log`.

كل أداة تقبل أيضًا `-AnalyzeOnly` و `-WhatIf` مباشرة:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\09-Security\SE01-SecurityAudit.ps1" -AnalyzeOnly
```

## نموذج الأمان (ملخص)

| الرمز | المستوى | المعنى |
|-------|---------|--------|
| RO | READ_ONLY | فحص فقط، لا يغيّر شيئًا |
| SC | SAFE_CLEANUP | تنظيف آمن؛ الملفات تُنقل إلى الحجر قبل الحذف |
| SR | SYSTEM_REPAIR | إصلاح حالة النظام؛ قد يتطلب صلاحيات مسؤول |
| DX | DESTRUCTIVE | حذف/استبدال بيانات النظام؛ يتطلب كتابة عبارة تأكيد |
| RB | REBOOT_REQUIRED | يسري الأثر بعد إعادة التشغيل |
| WR | WINRE_ONLY | يجب تشغيله من بيئة الاستعادة |

للتفاصيل: `Docs\SAFETY-MODEL.md`.

## تشغيل الاختبارات

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\Tests\Run-Tests.ps1"
```

رمز الخروج 0 يعني نجاح جميع الاختبارات الـ 83 (على Windows PowerShell 5.1 وpwsh). جميع الأدوات الـ 100 تم تنفيذها والتحقق منها سلوكيًا. الحزمة **جاهزة** للإنتاج.

## فهرس الأدوات

يصف `Docs\TOOLS-MANIFEST.csv` / `Docs\TOOLS-MANIFEST.json` الأدوات الـ 100 بنظام من 15 حقلاً
(المعرف، الفئة، المسار، الاسم الإنجليزي، الاسم العربي، الغرض، مستوى الخطر، متطلبات المسؤول،
متطلبات إعادة التشغيل، إمكانية العمل دون اتصال، طريقة النسخ الاحتياطي، طريقة الاسترجاع، دعم
التحليل فقط، دعم WhatIf، نتيجة الاختبار). ويسرد `Docs\FILE-INVENTORY.json` محتويات الحزمة بدقة.

## ملاحظات التغليف

لا يتضمّن ملف ZIP بيانات التشغيل (`Reports\`, `Logs\`, `Quarantine\`, `Backups\`) ولا شجرة
البرامج النصية القديمة `Scripts\` ولا ملفات الإصدار 1.x (`KnouxRepair-Launcher.ps1`,
`KnouxRepair.Manifest.json`).
